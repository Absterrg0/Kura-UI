# @kura-ui/react

AI-native React components — see the [main README](https://github.com/Absterrg0/Kura-UI).

```bash
npm install @kura-ui/react
```

```css
@import "tailwindcss";
@import "@kura-ui/react/styles.css";
```

```tsx
import { ShimmerText } from "@kura-ui/react/shimmer-text";
import { useAudioAnalyser } from "@kura-ui/react/hooks";
import { cn, springs } from "@kura-ui/react/utils";
```

Each component is a separate entry point (`@kura-ui/react/<slug>`). Requires React 19 and Tailwind CSS v4.

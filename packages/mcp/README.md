# @kura-ui/mcp

MCP server (stdio) that lets coding agents discover, understand and install
[Kura UI](https://github.com/Absterrg0/Kura-UI) components.

## Tools

| Tool                       | Input                                                                                                   | Returns                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `list_components`          | `category?`, `tag?`                                                                                     | slug, name, category, status, description, tags (+ hooks)                                        |
| `search_components`        | `query`, `limit?`                                                                                       | ranked matches for a natural-language need, with matched fields                                  |
| `get_component`            | `slug`                                                                                                  | full manifest: whenToUse/whenNotToUse, props + JSON Schema, anatomy, a11y, examples, agent notes |
| `get_component_source`     | `slug`, `includeDependencies?`                                                                          | source files (shadcn-style `@/` imports), optionally with hooks/libs it needs                    |
| `get_install_instructions` | `slug`, `method?` (`shadcn`·`cli`·`npm`·`manual`), `framework?` (`next`·`vite`·`remix`·`astro`·`other`) | exact steps; `manual` inlines every file                                                         |
| `get_design_tokens`        | `includeCss?`                                                                                           | OKLCH tokens (light/dark), utility names, motion presets, optionally kura.css                    |
| `get_design_guidelines`    | —                                                                                                       | DESIGN.md (Washi & Sumi design language)                                                         |

## Configure

**Claude Code**

```bash
claude mcp add kura -- npx -y @kura-ui/mcp
```

**Cursor** — `.cursor/mcp.json`

```json
{ "mcpServers": { "kura": { "command": "npx", "args": ["-y", "@kura-ui/mcp"] } } }
```

**Codex** — `~/.codex/config.toml`

```toml
[mcp_servers.kura]
command = "npx"
args = ["-y", "@kura-ui/mcp"]
```

**Any MCP client (local checkout)**: `node packages/mcp/dist/index.js` after `pnpm build`.

## Data

The server reads a catalog snapshot bundled at publish time (`data/catalog.json`, generated by
`pnpm generate`). Set `KURA_REGISTRY_URL=https://kuro.abstergo.fyi` to read the live catalog instead.
